# Limited editions

Use the collection navigation or open `?list=limited` to browse `watches-limited.json`. This separate catalogue contains ten researched, quantity-limited references, with real manufacturer photos, published production counts, sources, specifications and personal fit notes. The existing `watches.json` remains the main wishlist.

Run `python3 scripts/validate_collections.py` and `node --check app.js` before deployment. GitHub Actions validates and uploads both catalogues to Azure Storage. Stock notes are specific to the sources checked on 2026-10-30; these are collection candidates, not ten confirmed purchase offers. Unknown EUR prices remain null. The Baltic is an aspirational exception above the usual budget.
